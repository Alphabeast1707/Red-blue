Evidence workflow

Collect, train, evaluate

01 / CAPTURE

Collect controlled benign traffic

Successful requests to local DVWA are recorded with your reviewer identity.

docker compose exec cyberranger-runner python scripts/capture_benign.py --reviewer your_name
02 / TRAIN

Train a local candidate

Run on the host to avoid Docker's memory limit. This writes a candidate and never replaces the active detector.

source .venv/bin/activate && python scripts/train_laya.py --dry-run
source .venv/bin/activate && python scripts/train_laya.py --device cpu --freeze-encoder
03 / EVALUATE

Compare on observed requests

Review held-out metrics and sample counts before deciding whether to promote.

source .venv/bin/activate && python scripts/evaluate_laya_checkpoint.py --model blue_detector/models/laya-candidate

Corpus data stays local in data/traffic.jsonl. Failed requests, unlabeled candidates, and fabricated rows are excluded from training.
